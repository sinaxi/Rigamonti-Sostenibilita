# Rigamonti — Landing Sostenibilità

Landing istituzionale del Gruppo Rigamonti, fedelmente basata sul layout PDF annotato.

## Avvio

```bash
npm install
npm run dev
```

Build produzione: `npm run build` → cartella `dist/`.

## Note dai commenti PDF

- Font: famiglia **Jost** in `public/fonts/`
- Tre slider indicatori (infografiche ricostruite in HTML + icone)
- Switch brand → certificazioni in `public/images/certificazioni/`
- Burger menu: placeholder (navigazione futura)
- Documenti download: non ancora definiti (link disabilitati)
- Privacy / Cookie: da allineare al sito principale
